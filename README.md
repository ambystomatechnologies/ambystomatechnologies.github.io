# 🌐 Portal Oficial de Ambystoma Technologies
### Sitio Web Principal y Catálogo de Aplicaciones
**URL en Vivo:** [https://ambystomatechnologies.github.io/](https://ambystomatechnologies.github.io/)

---

## 📁 Estructura de este Proyecto
- `index.html`: Página principal con diseño responsivo Dark Mode, catálogo de proyectos y publicidad AdSense (`pub-5786595894984320`).
- `ads.txt`: Archivo oficial de autorización publicitaria de Google AdSense.
- `logo.png`: Logotipo oficial de Ambystoma Technologies.
- `favicon.svg` y `favicon.ico`: Ícono de la marca para la pestaña del navegador.
- `start.bat`: Previsualizador local en `http://localhost:8081`.

---

## 🚀 Cómo publicar cambios
Cualquier cambio que realices en `index.html` se publica en vivo ejecutando:
```bash
git add .
git commit -m "Actualizar portal"
git push origin main
```
En menos de 30 segundos, los cambios estarán en vivo en **https://ambystomatechnologies.github.io/**.
